# Architecture Decision Records (ADR)

## 日本語

このフォルダーには、このプロジェクトの重要な設計判断を記録しています。
各 ADR には、背景（Context）、決定内容（Decision）、影響（Consequences）、検証（Validation）をまとめています。

### ADR 一覧

- [ADR-001: アプリ設定・保護・フィードバック](ADR-001-app-completion.md)
- [ADR-002: ミッション達成数に応じたアバター解放](ADR-002-avatar-mission-unlocks.md)

新しい設計判断を追加するときは、`ADR-003-<短い名前>.md` の形式でファイルを作成し、この一覧にも追加してください。

## English

This folder stores important architecture decisions for the project.
Each ADR describes the context, decision, consequences, and validation of one design choice.

### ADR index

- [ADR-001: App settings, protection, and feedback](ADR-001-app-completion.md)
- [ADR-002: Avatar unlocks based on completed missions](ADR-002-avatar-mission-unlocks.md)

When adding a new decision, use the `ADR-003-<short-name>.md` filename format and add it to this index.
