# ADR-002: ミッション達成数に応じたアバター解放

- **Status:** Accepted
- **Date:** 2026-08-21
- **Related commits:** `6c9cc9c`, `fd568e5`, `5c1f7eb`, `8500692`, `0b0baf9`

## Context

子どもがミッションに取り組む動機として、達成数に応じて自分のアバターを増やせる仕組みを追加する。
初期状態では選択肢を絞り、ミッションを続けることで動物とオリジナルアバターのパーツが増えていく設計にする。

また、動物のプリセットだけが解放されて、同じ動物に対応するオリジナルパーツがロックされたままになると、
子どもが「なぜこのパーツは使えないのか」を理解しにくい。そのため、動物と対応パーツは同じ達成数で解放する。

## Decision

### 1. 初期状態はうさぎだけを使えるようにする

アバター選択画面では、うさぎのアイコンを左端に配置する。新規状態では、うさぎ以外の動物と「じぶんで つくる」をロック表示する。

ロックされた項目は、鍵アイコンと解放までに必要なミッション数を表示する。タップされた場合も、残りの必要数をToastで知らせる。

### 2. 動物と解放回数を固定する

ミッション達成数は端末内の累計値として扱い、次の回数で解放する。

| 達成ミッション数 | 解放内容 |
|---:|---|
| 10 | ねこさん＋ねこみみ |
| 15 | いぬさん＋たれみみ |
| 20 | とらさん |
| 25 | ぞうさん＋ぞうみみ＋ぞうのはな |
| 30 | じぶんで つくる（カスタムアバター） |

### 3. 対応するカスタムパーツを同時に解放する

`modules/shared/avatars.js` の `AVATAR_ANIMAL_PARTS` で動物とパーツの関係を定義する。

- うさぎさん：うさみみ（初期解放）
- ねこさん：ねこみみ
- いぬさん：たれみみ
- ぞうさん：ぞうみみ、ぞうのはな

カスタムアバター自体は30回で解放する。カスタムアバターが使えるようになった時点で、すでに解放条件を満たしている動物パーツは利用できる。

その他の汎用パーツは、35回以降、5回ごとに次の順番で解放する。

1. くりーむ色
2. そら色
3. もも色
4. わかば色
5. すみれ色
6. つの
7. きらきらのおめめ
8. にこにこのおめめ
9. わーいのおくち
10. ねこぐち
11. リボン
12. かんむり
13. はっぱ

### 4. ミッション達成数を保存する

`js/Session.js` に `completedMissionCount` を追加し、`ehon.session.v2` に保存する。

- 同じプレイ中に同じ `missionId` を再撮影・再保存しても、達成数は重複加算しない。
- 新しい `missionId` を達成したときだけ1回加算する。
- リロード後も値を復元する。
- 親向けのデモ用リセットでは、アバターとともに達成数も0に戻す。
- 新しい部品が解放された達成画面では、解放内容をToastで通知する。

### 5. 配信キャッシュを回避する

GitHub Pages の静的ファイルキャッシュで、更新直後に古いES Modulesがブラウザに残ることがあった。
そのため、アプリのエントリーポイント、`Session`、画面ルーター、Home、達成画面、AvatarモジュールのURLにバージョンパラメータを付ける。

今回のバージョンは `v=8500692` とし、更新後は新しいURLでモジュールを取得できるようにした。

## Consequences

### Positive

- ミッション達成がアバターの成長に直接つながる。
- うさぎを入口にして、10回・15回・20回・25回・30回という明確な目標を示せる。
- 動物と対応パーツが同時に解放されるため、解放状態の不一致が起きにくい。
- 達成数と解放状態は同じ端末・同じブラウザで維持される。

### Limitations

- 達成数は端末内の `localStorage` に保存され、端末やブラウザをまたいで同期しない。
- localStorageを削除すると、達成数と解放状態も失われる。
- 正式版で複数の子どもやアカウントを扱う場合は、サーバー側の進捗管理が必要になる。
- 現在、とらさんには専用のカスタムパーツを設定していないため、既存の汎用パーツを使う。

## Validation

- `node --check` で変更したJavaScriptを検証
- `npm run web:build` が成功
- `python3 tools/validate_content.py` が警告0件
- ブラウザで0回・10回・25回・30回のロック状態を確認
- 30回時に、ぞうみみ・ぞうのはなが解放されることを確認
- GitHub Pages のデプロイが成功
- 公開URLでバージョン付きエントリーと10/15/20/25/30の解放定義を確認
