# えほん web（プロトタイプ）

前回 Flutter で作った絵本アプリを **HTML / CSS / JS + JSON + Python** に置き換えた web 版。
Flutter版のコアループ（モード選択 → 絵本選択 → 物語 → ミッション → 撮影 → 達成演出 → 絵本日記 → ギャラリー）をそのまま再現している。
Dart を書ける人がいなくてもチームで触れて、URL / QR で審査員のスマホにそのまま配れる。

三層分離は前回と同じ：**コンテンツ**（JSON+アセット）／**ロジック**／**プレゼンテーション**。

---

## うごかす（PCで見る）

このフォルダで:

```bash
python3 serve.py
```

表示された `http://localhost:8000` をブラウザで開く。

> ダブルクリックで index.html を直接開くと、ブラウザの制約で JSON を読めない。
> かならず上のサーバー経由で開くこと（Python標準機能だけでOK）。

## 同じ Wi-Fi の iPad / iPhone で見る

1. PC と iPad を **同じ Wi-Fi** につなぐ
2. PCで `python3 serve.py` を実行
3. 表示される `http://<PCのIP>:8000` を **iPad の Safari** で開く
4. Safariの共有 →「ホーム画面に追加」でアプリっぽく使える（PWA）

写真撮影はファイル入力（`<input capture>`）で端末のカメラを開くので、**http のままでも動く**（`getUserMedia` と違い HTTPS 不要）。

## いじる場所（＝馴染みの言語だけ）

| やりたいこと | 触るファイル | 言語 |
|---|---|---|
| 絵本・ミッションの中身 | `content/books/<絵本>.json`（1冊1ファイル） | JSON |
| 絵本の並び順・追加 | `content/library.json`（索引） | JSON |
| イラスト・音声の差し替え | `content/assets/` | 画像/音声 |
| 各画面の見た目・構成 | `js/screens.js` / `css/style.css` | JS / CSS |
| 画面のつなぎ（ルーター） | `js/app.js` | JS |
| コンテンツ検証 | `tools/validate_content.py` | Python |
| サーバー起動 | `serve.py` | Python |

`js/ContentRepository.js` / `js/Session.js` はロジック層。基本さわらなくていい。

## 画面（Flutter版の再現）

`MODE`（こども/おうちのひと選択）→ `PIN`（おうちのひとゲート, プロト用 **0000**）→ `PARENT`（レポートのモック）
`HOME`（えほん/おもいで）→ `SELECT`（絵本選択）→ `STORY`（物語・ミッション）→ `PREVIEW`（これにする/もう一回）→ `ACHIEVE`（達成演出・シール）→ `COMPLETE` → `DIARY`（絵本日記）
各モードの `SETTINGS`（BGM・効果音・朗読・文字サイズ・アニメーション・テーマ・プライバシー）から表示と音を調整できる。

- ミッション達成は **写真撮影** が基本。カメラを使わないときは「できた！」でタップ達成（フォールバック）。
- ストリークは「外で活動した日数」に付き、途切れても没収しない（健全設計）。
- ミッションには `developmentDomains`（発達領域タグ）を持たせてある（Stage 3 分析の布石）。

## 共同編集・くわしい編集方法

- 複数人で編集する手順（Git / GitHub / Pages）… **`GITHUB手順.md`**
- 画面・演出・記録の具体的な編集レシピ（初学者向け）… **`編集ガイド.md`**

## コンテンツの書き方

絵本は **1冊1ファイル**（`content/books/<絵本>.json`）。`content/library.json` はその索引（並び順）です。
各絵本ファイルの `pages[]` にページを並べます。ページの `type`:

- `story` … お話（`text` + `image`）
- `mission` … 屋外ミッション（`prompt`=やること、`diaryCaption`=日記の一言、`developmentDomains`=発達領域タグ）
- `end` … 最後（これに到達すると絵本日記を生成）

差し替えたら配布前に検証:

```bash
python3 tools/validate_content.py
```

## いまの割り切り（盛りすぎ防止）

- 画像は仮のSVGプレースホルダー。イラスト担当が差し替える前提。
- 音声は参照だけ用意（実ファイルなし。無ければ黙ってスキップ）。
- **撮った写真は IndexedDB に保存される**（`js/Storage.js`）。リロードしても思い出ギャラリーと
  読みかけの本（ページ位置＋撮った写真）は消えない。読みかけの本には本棚で「つづきから」バッジが付く。
  デモ用リセット（おうちのひとレポートのボタン）で全部消せる。
- **設定はブラウザ内に保存される**（`js/Settings.js`）。朗読は現在「開発中」で、初期状態はオフ。
  専用音源がないページでのブラウザ標準読み上げは試用機能として残している。
  現在の画面言語は日本語のみで、中文・English は翻訳リソース追加後に開放する。
- 初回起動では、こども・おうちのひと・写真ミッションの使い方を案内する。保存成功、ミッション完了、読み込み失敗も画面上で知らせる。
- **PIN は3回連続で間違えると30秒ロックされる**。保護者モードは5分間操作がないとMODEへ戻る。
- 親レポートは1画面のモック。本物の課金・家族招待・複数子対応は未実装。
